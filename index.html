Full-Stack • Node.js • MongoDB 2024–2025

AptitudePro — Online Aptitude Learning & Performance Analysis System

Problem Solved:

Campus placement candidates require structured, gamified aptitude preparation with realistic company patterns, detailed performance tracking, and hands-on coding and SQL practice in one unified platform.

Key Features & Architecture:

  • 195 Levels Across 9 Tiers: Timed quizzes in 5 core sections (Maths, Logical, English, Programming, Mixed) plus company-specific tracks for TCS, Infosys, and Wipro.
  • MongoDB Schema with Mongoose: Designed data models for users, questions, results, section progress, user stats, and XP history; stored answer snapshots so past attempts preserve their solutions even if question banks update.
  • Session Security & Auth: Implemented session-based authentication with bcryptjs password hashing, express-validator input checks, role-based route protection (user/admin), and Helmet security headers.
  • Analytics & Review Service: Automated quiz evaluation, XP and tier leveling, and question-by-question review with step-by-step mathematical formulas.
  • In-Browser SQL Practice Console: Embedded an interactive SQL querying sandbox powered by sql.js.
